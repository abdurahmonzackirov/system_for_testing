## 📌 Описание

Полнофункциональный Telegram бот для проведения онлайн тестирований и контроля знаний учащихся. Система поддерживает несколько предметов, темы, вопросы с вариантами ответов и автоматическое отслеживание прогресса студентов.

### ✨ Ключевые особенности:

- 👤 **Многоуровневый доступ** - пользователи и администраторы
- 📚 **Управление контентом** - предметы, темы, вопросы
- ✅ **Интерактивное тестирование** - реальное время, мгновенная обратная связь
- 📊 **Анализ прогресса** - статистика, рейтинги, слабые места
- 📁 **Массовый импорт** - загрузка контента через Excel
- 🎯 **Адаптивное обучение** - рекомендации по слабым темам
- 📝 **Подробное логирование** - отслеживание всех действий с датой и временем

## 🚀 Быстрый старт

### Требования

```bash
Python 3.8+
PostgreSQL 17
pgAdmin 4
pip
```

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/abdurahmonzackirov/system_for_testing
cd education-testing-bot
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Получите токен бота:**
   - Напишите [@BotFather](https://t.me/botfather) в Telegram
   - Создайте нового бота и скопируйте токен

4. **Настройте переменные окружения:**
```bash
# Создайте файл .env
echo "BOT_TOKEN=your_token_here" > .env
```

5. **Запустите бота:**
```bash
python run.py
```

## 🎮 Использование

### Для пользователя:

1. Напишите боту `/start`
2. Пройдите регистрацию
3. Выберите предмет и тему для изучения или тестирования
4. Отвечайте на вопросы
5. Просматривайте свою статистику и прогресс

### Для администратора:

1. Добавьте свой ID в список администраторов
2. Напишите боту `/start`
3. Используйте админ-меню для управления контентом
4. Загружайте данные через Excel импорт

#### Формат Excel для импорта вопросов:

```
ID Предмета | Название Предмета | ID Темы | Название Темы | Название Вопроса | Текст | Варианты (A|Б|В|Г) | Правильный ответ | Баллы
1           | Математика        | 1       | Алгебра        | Вопрос 1         | 2+2=? | 3|4|5|6             | Б               | 10
```
